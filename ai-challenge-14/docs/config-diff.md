## Wording chosen for this demo

The brief does not define an ESCALATED state, so every message and notification text below is our own wording, not taken from the brief. (The only message the brief specifies is the info-request cycle limit, "Maximum information requests exceeded — escalate to team lead", which is in the base config and unchanged.)

- `escalate` `notify` → `role:team_lead`: "Claim {{id}} has been escalated for review: {{escalationReason}}"
- `return_to_assessment` `cycleLimit.message`: "Claim has already been returned to assessment once — team lead must decide"
- `return_to_assessment` `notify` → `user:assessorId`: "Claim {{id}} has been returned to you for assessment"
- `reject_escalated` `notify` → `member`: "Claim {{id}} has been rejected: {{rejectionReason}}. To appeal, contact our claims office with claim ID {{id}} before the appeal period ends."
